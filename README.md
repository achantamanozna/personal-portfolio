# Personal Portfolio Website

A responsive personal portfolio built with HTML, CSS, JavaScript and a small Node.js/Express backend.

## Features
- Responsive design
- Dark/light mode
- Projects section
- Skills section
- Activities section
- Contact form connected to an Express API
- Mobile navigation

## Run locally

### 1. Start the backend
```bash
cd backend
npm install
npm run dev
```

Backend:
http://localhost:5000

### 2. Open the frontend

Open `frontend/index.html` in your browser.

For the best local-development experience, you can also use VS Code's Live Server extension.
